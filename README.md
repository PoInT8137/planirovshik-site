# Планер

Неофициальное приложение для студентов МАУ (Мурманский арктический университет):
расписание пар и время, когда выходить из дома, чтобы успеть к первой паре.

**Открыть: https://point8137.github.io/planirovshik-site/**

## Что умеет
- Показывает, во сколько выходить: начало пары − (дорога + запас + погода).
- Расписание своей группы, любой другой группы или преподавателя на неделю.
- «Как доехать»: на какую остановку идти и на какой автобус или троллейбус садиться.
- Уведомления, если у группы поменялось время, аудитория или пара отменилась.
- Работает без интернета: последнее расписание хранится на телефоне.

## Установка
**iPhone:** открой ссылку выше в **Safari** → «Поделиться» → «На экран „Домой“» → «Добавить».

**Android:** открой ссылку в **Chrome** → меню ⋮ → «Установить приложение».

## Источники данных
- Расписание — открытый сайт университета [mauniver.ru](https://mauniver.ru/).
- Расписание автобусов и троллейбусов — АО «Электротранспорт города Мурманска».
- Остановки и маршруты — © участники [OpenStreetMap](https://www.openstreetmap.org/copyright).

Время на транспорте рассчитывается **по расписанию**, а не по реальному положению машин.
